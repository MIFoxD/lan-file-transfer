# 局域网文件互传（LAN File Transfer）

跑在局域网内的私密文件互传小工具：网页上传/下载，上传时指定接收人并实时通知对方查收，对方下载后实时回执"谁在什么时候下载了"。无需注册账号，输个昵称就能用，手机/电脑浏览器通用。

## 功能特性

- 📤 **网页上传/下载**：拖文件到页面任意位置或点右下角 ＋，选接收人即可发送，带实时进度条
- 🔒 **私密投递**：只有指定的接收人能看到并下载该文件，其他人不可见（服务端强制鉴权）
- 📥 **查收通知**：有人给你发文件时，页面实时弹出提醒 + 收件箱未读角标 + 标题计数
- ✅ **下载回执**：对方下载后，你实时收到"X 于 HH:mm:ss 下载了《文件名》"，发件箱可查看完整下载历史（60 秒去重，重复下载/断点续传不会轰炸通知）
- 🗑 **手动删除**：上传者可随时删除文件，磁盘立即清理，对方列表实时同步移除
- 📱 **移动端适配**：响应式布局，iPhone/Android 浏览器直接可用
- 🔌 **实时推送**：基于 SSE（Server-Sent Events），断线自动重连 + 60 秒轮询兜底

## 技术栈

- **后端**：Python 3 + Flask（路由）+ waitress（生产级 WSGI 服务器，32 线程）+ SQLite（标准库，WAL 模式）
- **前端**：原生 HTML/CSS/JS 单页，无构建步骤；SSE 实时推送；XHR 上传进度
- **零外部服务**：不依赖任何第三方云服务，数据全部在本机 `data/` 目录

## 快速开始

```bash
# 首次：创建虚拟环境并安装依赖（只需一次）
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 启动
.venv/bin/python app.py
```

启动后终端会打印访问地址：

```
本机访问:   http://127.0.0.1:8000
局域网访问: http://192.168.x.x:8000   ← 同一 Wi-Fi 下的手机/电脑打开这个
```

> macOS 首次运行若弹出"是否允许 Python 接受传入网络连接"，请选择**允许**。

## 使用说明

1. **首次打开**：输入昵称进入（昵称在局域网内唯一，无需密码）
2. **发文件**：拖文件到页面任意位置（或点 ＋）→ 选择接收人 → 发送，带进度条
3. **收文件**：收件箱出现新文件并有角标提醒，点"下载"即可
4. **看回执**：发件箱中每个文件下方可展开下载记录
5. **删文件**：发件箱点"删除"，文件立即从服务器磁盘移除

### iPhone/iPad 用户注意

- 请用 **Safari** 打开地址（微信内置浏览器会阻止文件下载）
- 下载的文件保存在 **"文件" App → 下载项** 中，图片/视频**不会自动出现在相册**；
  需要的话在"文件"里长按 → 存储到相册

## API 一览

除 `GET /` 与 `POST /api/register` 外均需登录（HttpOnly cookie 鉴权）。错误统一返回 `{"error": "消息"}`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/me` | 当前登录用户 |
| POST | `/api/register` | 注册昵称并签发 cookie（昵称重复 409） |
| GET | `/api/users` | 全部用户及在线状态（选择接收人用） |
| GET | `/api/files/inbox` | 我收到的文件（含我的下载状态） |
| GET | `/api/files/outbox` | 我发出的文件 + 每个文件的下载记录 |
| POST | `/api/files` | multipart 上传（`file` + `recipient_id`），成功推 `file_received` |
| GET | `/api/files/<id>/download` | 仅接收人；支持 Range 断点续传；记录下载并推 `file_downloaded` |
| DELETE | `/api/files/<id>` | 仅上传者；删磁盘 + 软删除 + 推 `file_deleted` |
| GET | `/api/events` | SSE 推送流（15 秒心跳，per-user 多标签页分发） |

## 实现要点

- **身份机制**：昵称注册即签发 HttpOnly + SameSite=Lax cookie（一年有效），无密码，适配局域网可信环境
- **私密性在服务端强制**：列表 SQL 层按用户过滤；下载/删除逐一校验身份，越权返回 403/404
- **下载通知去重**：Range 续传请求不记录；同一用户 60 秒内重复下载同一文件不重复通知
- **大文件友好**：上传流式落盘（`.tmp-*` + 原子改名），下载支持 Range 断点续传，不把文件读进内存
- **文件安全**：磁盘一律 uuid 命名，原始文件名仅存数据库；下载时 RFC 5987 编码中文名，ASCII 回退名安全可读
- **服务器选型**：使用 waitress 而非 Flask 开发服务器——iOS Safari 下载管理器对开发服务器的连接处理不兼容会导致下载卡死

## 已知限制

- **昵称即身份**：没有密码，依赖浏览器 cookie 识别（有效期一年）。清除浏览器数据后无法用原昵称（属占用状态），需换新昵称；管理员可删除 `data/app.db` 中对应 users 行来释放昵称
- 仅适用于可信的局域网环境，**请勿暴露到公网**
- 服务器重启后，未收到的实时弹窗不会重放，但收件箱/发件箱列表与下载历史完整保留
